# Stellar Burger App

Интерактивное SPA-приложение для сборки бургеров. Пользователь может регистрироваться, логиниться, просматривать заказы и собирать и заказывать собственные бургеры.

## Технологии

- **React**
- **React Router**
- **Redux Toolkit**
- **TypeScript**
- **CSS Modules**
- **Jest / Cypress** — для тестирования

## Запуск проекта

### 1. Установка зависимостей

```bash
npm install
```

### 2. Переменная окружения
Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. 
Добавьте`BURGER_API_URL=https://norma.nomoreparties.space/api` в файл ```.env```
### 3. Запуск проекта в dev-режиме

```bash
npm start
```
Проект запустится по адресу http://localhost:4000/

## Тестирование:

Для запуска тестов используйте следующие команды:
#### Запуск Jest тестов:

```bash
npm test
```
#### Запуск Jest тестов с генерацией отчёта о покрытии кода (coverage):
```bash
npm run test:coverage
```
#### Запуск E2E тестов в Cypress в headless-режиме (без открытия браузера):
```bash
npm run cypress:run
```
#### Запуск E2E тестов в Cypress в интерактивном режиме:
```bash
npm run cypress:open
```
